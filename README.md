# JeanLuisDEV — Central de Privacidade

Site estático pronto para GitHub Pages, Netlify ou Vercel.

## Publicação no GitHub Pages
1. Crie um repositório público.
2. Envie todos os arquivos desta pasta para a raiz.
3. Em Settings > Pages, selecione Deploy from a branch e a branch main.

Antes de publicar o app de previsão do tempo, informe nesta política o nome e a política do provedor da API meteorológica.
